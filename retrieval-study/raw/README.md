# 验证记录范围

本目录提交查询响应、差分摘要、导入一致性摘要、测试结果和诊断结果。文档与编号均为受控合成数据。失败与未完成实验保留原状态，不作为成功验证使用。

以下内容保留在原工作目录，不提交到公开仓库：

- 完整服务器构建日志和服务器运行日志：可能包含本机环境或临时启动参数。仓库保存构建状态快照。
- `server-data/`、临时 API 密钥、工具链、依赖归档和二进制构建缓存。
- 大批逐条导入确认记录与生成的数据：保留生成器、参数、导入计数和导出摘要，可按种子重建。
- 原生性能采样文件；可读的调用图和测量结果仍保留。

`manifests/` 中公开上游审计记录只保留查询、版本、状态、链接和核验元数据，省略下载的正文、评论与发行说明。发布清单记录本次文件的校验和。报告中引用的本机构建日志路径用于定位原始证据，不表示该日志已公开。

各次构建的来源、编译选项与哈希记录已单独归档到 `../manifests/build-records/`。这些记录与本机对应的 `builds/<名称>/manifest.json` 内容一致，可在不上传构建缓存的情况下审查实验来源。`server-build-snapshot-current-20261028.json` 是当前成功构建快照，旧的失败快照按历史保留。
